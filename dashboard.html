API Contracts

JSON payloads and routing requirements connecting backend microservices.

POST /api/v1/auth/signup Create user profile

Registers a new account. Hashes credentials using Argon2id/Bcrypt and returns a JWT session token.

  "email": "farmer.john@farm.com",
  "password": "secure_password_123"
}

GET /api/v1/treatments/:key Lookup disease recommendations

Fetches static details, preventive lists, and organic/chemical advice for a specific disease class.

  "display_name": "Tomato Early Blight",
  "description": "Fungal disease caused by Alternaria solani...",

POST /api/v1/diagnose Submit leaf image for AI diagnosis

Direct multipart upload to the Python AI service. Returns localized bounding boxes and Grad-CAM overlays encoded as Base64.

Request Payload (Multipart Form)

Headers: Authorization: Bearer <token>
Body: 
  image: binary_file_bytes.jpg

Inference Sequence Flow

Trace the lifecycle of a leaf diagnostics request moving across container layers.

1

Client Submits Request

Mobile/Web upload sends the raw leaf image along with security tokens to the API Gateway.

2

Gateway Route & Verification

Gateway inspects the JWT, validates rate-limits, and forwards request to internal services.

3

Core Database Registration

Go Core writes a persistent record entry initialized with 'pending' status and geotags.

4

AI Preprocessing & Triton Inference

FastAPI decodes image bytes, runs aspect padding, and queries Triton gRPC to compute predictions.

5

XAI Generation & Client Broadcast

Grad-CAM superimposes heatmap highlights onto the leaf. Results are saved, and WS alerts the client.
