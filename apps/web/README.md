# Web Application Client

This directory contains the React SPA frontend application built with Vite and TypeScript.

## Responsibilities
- Provide a responsive layout for desktop, tablet, and mobile web browsers.
- Handle image selection, capture (via webcam APIs), and multi-upload queuing.
- Render plant disease diagnostic overlays (bounding boxes and classification indices).
- Render visual explainability maps (saliency heatmap overlays generated by Grad-CAM).
- Display organic and chemical treatment cards and structured prevention lists.
- Track search and diagnosis history for authenticated users.

## Recommended Structure
```
web/
├── public/              # Static assets
└── src/
    ├── assets/          # CSS, images, and fonts
    ├── components/      # Shared presentation UI components
    ├── hooks/           # Custom React hooks (React Query integrations)
    ├── pages/           # Page views (Dashboard, Diagnoser, History)
    ├── services/        # Client API gateways and wrappers
    ├── store/           # Local state management (Zustand config)
    ├── types/           # Type declarations
    ├── App.tsx          # App component routing definition
    └── main.tsx         # Mount node hook
```
